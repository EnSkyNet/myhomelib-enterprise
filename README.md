# MyHomeLib Enterprise 8.0.0 R18

MyHomeLib — настільний застосунок для локальної електронної бібліотеки (Java 21, JavaFX, SQLite, Lucene). Є Reader, організатор, імпорт INPX, пошук, експорт і необов’язкові інтеграції. **SQLite і файли книг — дані користувача; не тестуйте зміни на єдиній копії бібліотеки.**

## Збірка й запуск

Потрібні JDK 21 та Maven 3.9.6+ (або попередньо підготовлені офлайнові залежності).

| Завдання | Linux / macOS | Windows PowerShell |
|---|---|---|
| Швидка компіляція десктопа без тестів, для локальних правок | `./build.sh --fast` | `.\build.ps1 --fast` |
| Повна перевірка всього репозиторію (21 Maven-проєкт) | `./build.sh` | `.\build.ps1` |
| Запустити застосунок з вихідного коду | `./run.sh` | `.\run.ps1` |
| Підготувати настільний пакет | `./package-desktop.sh` | `.\package-desktop.ps1` |

**Релізне правило:** `--fast` не запускає тести й ніколи не є підставою для випуску. Перед релізом необхідні повний `clean verify`, перевірка пакування та ручне приймання на цільовій ОС.

## Де що змінювати

- `myhomelib-ui` — JavaFX-інтерфейс і локалізація (`Lang/`).
- `myhomelib-application`, `myhomelib-domain` — правила й сценарії роботи.
- `myhomelib-infrastructure` — SQLite/Flyway, Lucene, файлові й мережеві адаптери.
- `myhomelib-library-organizer` — аналіз, копіювання, журнал, скасування й відновлення.
- `myhomelib-reader` — формати й відображення книг.
- `myhomelib-bootstrap` — запуск і компонування десктопа.
- `myhomelib-opds`, `myhomelib-web`, `myhomelib-mcp`, `myhomelib-plugin-*`, `myhomelib-converter-*` — додаткові інтеграції та інструменти; не вилучати їх без перевірки їхніх контрактів.

Наразі проєкт — **Linux release candidate**; відповідність Windows/NTFS/DPAPI і поведінка на робочій бібліотеці потребують окремих перевірок. Кількість автоматичних тестів не є підтвердженням production-ready.
