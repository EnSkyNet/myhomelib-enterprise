# MyHomeLib 8.0.0 — довідка

F1 — ця довідка. MyHomeLib керує кількома локальними та онлайн-колекціями, імпортує FB2/FBD/EPUB/TXT та книги з ZIP/7z/RAR, підтримує INPX, пошук, групи, оцінки, прогрес, відгуки, вбудовану читалку, зовнішні читалки та експорт на пристрій.

Основні розділи:
• Колекції — створення, INPX, онлайн-адреси, перемикання, резервне копіювання.
• Імпорт — окремі файли, каталоги, INPX, архіви.
• Пошук — звичайний і розширений; `%текст%`, `="точна фраза"`, `OR`.
• Читалка — FB2/FBD/EPUB/TXT, зміст, пошук, закладки, сноски, теми.
• Онлайн-доступ — завантаження відсутньої книги/архіву та скасування активного завантаження.
• Експорт — файли, FB2.ZIP, TXT, EPUB/PDF/MOBI/LRF через налаштовані зовнішні конвертери.
• Переносний режим — створіть порожній `myhomelib2.ini` поруч із програмою; дані, конфігурація та індекси зберігатимуться поруч із програмою.
• MCP — окремий сервер лише для читання; див. `MCP_README.md` у корені релізу.

## Доступність функцій

• **Настільний інтерфейс:** колекції, імпорт, локальна синхронізація папки, пошук і розумні колекції (Smart Collections), робота з книгами, читалка, експорт, резервне копіювання/відновлення, обслуговування, керування OPDS.
• **Веб / OPDS:** окремі серверні канали доступу. Їх наявність не означає окрему кнопку в настільному інтерфейсі для кожної серверної функції.
• **MCP:** окремий сервер лише для читання для зовнішнього MCP-клієнта.
• **Платформа розширень:** WebDAV-синхронізація користувацьких даних між пристроями, перегляд конфліктів синхронізації, Plugin SPI та точка розширення ШІ мають технічну основу в коді, але в MyHomeLib 8.0.0 не є завершеними стандартними сценаріями настільного застосунку. Не плутайте WebDAV-синхронізацію з командою **«Синхронізувати папку»**, яка працює з локальним каталогом файлів.
