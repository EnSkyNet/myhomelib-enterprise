# Колекції

MyHomeLib підтримує кілька незалежних колекцій. Колекцію можна створити порожньою, створити з INPX, підключити сучасну SQLite-БД або оригінальну `.hlc2`. Для старої Delphi `.hlc2` вихідний файл не змінюється: каталог переноситься в сучасну допоміжну SQLite-БД зі збереженням `LibID`.

Властивості колекції містять кореневу папку, тип, адреси книг/архівів, адресу INPX-оновлення та, за потреби, логін/пароль. Оновлення може виконуватися вручну з INPX або через мережу. Синхронізація папки додає нові файли та оновлює локальний стан наявних.

Для обслуговування доступні перевірка цілісності, `VACUUM`, перебудова пошукового індексу, резервне копіювання та відновлення. Книги можна копіювати між колекціями.
