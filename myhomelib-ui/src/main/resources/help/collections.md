# Колекції

MyHomeLib підтримує кілька незалежних колекцій. Колекцію можна створити порожньою, створити з INPX, підключити сучасну SQLite-БД або оригінальну .hlc2. Для старої Delphi .hlc2 вихідний файл не змінюється: каталог переноситься у сучасну sidecar SQLite-БД зі збереженням LibID.

Властивості колекції містять кореневу папку, тип, URL книг/архівів, URL INPX-оновлення та, за потреби, логін/пароль. Оновлення може виконуватися вручну з INPX або по мережі. Синхронізація папки додає нові та оновлює локальний стан файлів.

Для обслуговування доступні integrity check, VACUUM, rebuild search index, backup/restore. Книги можна копіювати між колекціями.
