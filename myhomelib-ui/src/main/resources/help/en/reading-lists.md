# Reading Lists

**Reading Lists** are user-owned ordered book lists. They do not modify Groups or Smart Collections.

- Create, rename, and delete lists.
- **Add selected books** adds all books checked in the main table; when there is no checkbox selection, it adds the current row selection.
- In the book context menu, **Add to reading list** adds the context book; when that book belongs to the current checkbox selection, the whole selection is added.
- Reorder with ↑/↓, **Alt+↑ / Alt+↓**, or drag and drop.
- **Start/continue list** opens the first available unfinished book in list order.
- Deleting a list never deletes book records or files; a catalog-deleted book is automatically removed from Reading Lists.

Reading Lists are included in portable backup/restore with membership and manual order.
