# Search

Search by title, author, series, genre, keywords, annotation, filename, publisher, language, library rating, year and date added. Saved search presets are supported.

Classic syntax: %text% for contains, ="exact phrase" for exact text, OR for alternatives. Field aliases such as title:, author:, series:, genre:, file:, lang:, publisher:, libid: are accepted. Numeric/date fields also support <, <=, >, >= and <>.
