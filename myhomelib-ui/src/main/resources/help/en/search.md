# Search

Search covers title, author, series, genre, keywords, annotation, filename and publisher; individual fields are also available through explicit aliases including `title:`, `author:`, `series:`, `genre:`, `file:`, `lang:`, `publisher:` and `libid:`. Sets of conditions can be saved as search presets.

Classic syntax: `%text%` for a contains wildcard, `="exact phrase"` for exact text, and `OR` for alternatives. `year`, `added`/`created`, `rate` and `library_rate` support `<`, `<=`, `>`, `>=` and `<>` comparisons. The advanced search form builds the same query model together with structured language, rating, year, date-added and local-availability filters.
