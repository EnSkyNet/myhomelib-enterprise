# Built-in Reader

The Canvas-based Reader is designed for predictable memory use. It supports FB2/FBD, FB2 in archives, EPUB and TXT, on-demand pagination, rich text, images, TOC, search, bookmarks, footnotes/internal links, selection/copy, themes, fonts, margins, justification, hyphenation, tap/swipe zones, keyboard navigation, fullscreen and autoscroll. Reading position is persisted.
