# Built-in Reader

The Canvas-based Reader is designed for predictable memory use. It supports FB2/FBD, FB2 in archives, EPUB, TXT and DRM-free MOBI/PRC/AZW/AZW3 (uncompressed or PalmDOC; HUFF/CDIC requires conversion), on-demand pagination, rich text, images, TOC, search, bookmarks, footnotes/internal links, selection/copy, themes, fonts, margins, justification, hyphenation, tap/swipe zones, keyboard navigation, fullscreen and autoscroll. Reading position is persisted.

Select text with an ordinary left-mouse drag. The selection menu immediately offers Highlight / Note / Dictionary / Translate / Copy. On touch devices, a long press selects a word while swipe gestures remain available for page navigation.
