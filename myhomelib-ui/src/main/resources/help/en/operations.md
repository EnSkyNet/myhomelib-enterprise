# Operation Center

**Operation Center** shows long-running and completed operations from the current session: type, stage, progress, start/end time, duration, result and error details.

For an active operation that supports cancellation, **Cancel** is available. Cancellation is complete only after cleanup of active work has finished. Completed entries can be cleared separately; clearing history does not delete books or successful operation outputs.

When another action conflicts with an active operation, MyHomeLib should explain what is blocking it instead of starting an incompatible operation.
