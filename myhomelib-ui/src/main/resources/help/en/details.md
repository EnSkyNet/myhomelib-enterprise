# Book details

The panel shows full catalogue metadata, navigable authors/series/genres, publisher, ISBN, languages, translators, TOC preview, text metrics, reading data and images.

For local FB2/EPUB files, metadata can be supplemented from the file. MOBI/PDF/DjVu use a safe fallback inspection path. File-derived data does not overwrite rating, progress, review or catalogue relationships when merge rules prohibit it.
