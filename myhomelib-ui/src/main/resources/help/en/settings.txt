# Settings

Configure UI language, confirmation for destructive actions, session restore, search indexing, external readers by extension, Calibre and external converters, device/export parameters, import, Reader, network options and other application settings. Built-in interface languages are Ukrainian, English and Bulgarian. Restart MyHomeLib after a language change to guarantee that every already-open window is refreshed.

WebDAV, plugins and AI providers are configured separately through **Sync, plugins and AI...**. Secrets must not be stored in plaintext; when secure storage is unavailable, integrations that require secrets are disabled.
