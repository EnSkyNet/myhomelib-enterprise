# Send to device / external tools

Configure a destination, filename/subfolder templates and optional external converters. After each successful export MyHomeLib can run a post-command. Placeholders include %DEST%, %TMP%, %FILE%, %FILENAME%, %TITLE%, %AUTHOR%, %SERIES% and %BOOKID%.

External readers can be configured per file extension. If no command is configured, the operating-system default application is used.
