# Export

Export selected books as supported source formats or convert FB2 with configured external converters to EPUB, MOBI, LRF or PDF. Filename and subfolder templates are supported. The current catalog list can be exported to HTML, TXT or RTF. The whole collection can be exported as INPX.

Personal user data can be exported/imported separately from the catalog and is linked by LibID.

Annotation Manager also has a dedicated Obsidian/Joplin Markdown export: one file per book, configurable folder/file/body templates, optional YAML frontmatter, and links back to MyHomeLib. By default, re-export replaces only a MyHomeLib-managed file owned by the same book id; unrelated notes are never overwritten and numbered duplicate files are not created automatically.
