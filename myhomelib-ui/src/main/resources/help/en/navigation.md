# Library navigation

The left panel contains Authors, Series, Genres, Years, Languages, Archives, Keywords, Groups, Reviews, Updates, Already read, History and All books modes.

For large libraries, authors are loaded by SQL for the selected initial letter instead of loading every author at once. The active global filter affects both the book list and navigation-node counters.

Select a node to open the corresponding book set. Back and Forward restore the previous or next navigation context.
