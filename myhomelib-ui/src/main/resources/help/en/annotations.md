# Annotations and notes

The **Annotations and notes** workspace shows highlights and notes from the whole library. It supports search by book, quote, note text, chapter and tags, plus filters by book, type, color, tag and date.

You can open an annotation in Reader, edit its note, color and tags, delete selected entries with confirmation, and undo the latest deletion. Batch actions can change color or add/remove tags for selected annotations.

Export supports UTF-8 CSV, Markdown, JSON, self-contained HTML, digest output and knowledge-management Markdown for Obsidian/Joplin. Markdown/HTML and knowledge export support templates; publication is staged so a failure or cancellation does not expose a partial result.

## Export to Readwise
The Readwise action exports annotations for books represented by the current row selection; with no selection it uses the active book filter, and otherwise exports the whole library. Unchanged annotations are not resent.
