# Import

Import individual files, directories or INPX catalogs. Reader/catalog formats include FB2, FBD, EPUB, TXT and DRM-free MOBI/PRC/AZW/AZW3 (uncompressed or PalmDOC; HUFF/CDIC requires conversion). Other supported documents such as PDF, DJVU, DOC/DOCX, ODT, RTF, HTML/HTM, MD and CHM are cataloged according to their available capabilities.

Archives: ZIP/FB2ZIP/CBZ/JAR, 7z, RAR/CBR, TAR, TAR.GZ/TGZ, TAR.BZ2/TBZ2, TAR.XZ/TXZ and CPIO. Large imports are batched and directory traversal is streaming.
