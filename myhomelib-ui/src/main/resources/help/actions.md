# Команди, гарячі клавіші та дії з книгою

Реєстр дій централізує ідентифікатори команд, гарячі клавіші, видимість та умови доступності. У налаштуваннях гарячих клавіш конфлікти перевіряються до збереження.

Дії з книгою можна об’єднувати в іменовані профілі з упорядкованим набором команд. Вони запускаються через `ProcessBuilder` без командної оболонки. Попередній перегляд показує масив аргументів (`argv`) і нічого не виконує.
