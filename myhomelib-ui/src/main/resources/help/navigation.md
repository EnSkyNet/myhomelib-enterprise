# Навігація бібліотеки

Ліва панель містить режими Автори, Серії, Жанри, Роки, Мови, Архіви, Ключові слова, Групи, Відгуки, Оновлення, Прочитані, Історія та Усі книги.

Для великих бібліотек автори завантажуються SQL-запитом за вибраною літерою, а не всі одразу. Активний глобальний фільтр впливає і на список книг, і на лічильники вузлів навігації.

Натисніть вузол, щоб відкрити відповідний набір книг. Команди «Назад» і «Уперед» повертають попередній або наступний контекст навігації.
