# Навігація бібліотеки

Ліва панель використовує режими Автори, Серії, Жанри, Роки, Мови, Архіви, Ключові слова, Групи, Відгуки, Оновлення, Прочитані, Історія та Усі книги.

Для великих бібліотек Автори завантажуються по вибраній літері SQL-запитом, а не всі одразу. Активний глобальний фільтр впливає і на список книг, і на лічильники navigation nodes.

Натисніть вузол, щоб відкрити відповідний набір книг. Back/Forward повертає попередній navigation context.
