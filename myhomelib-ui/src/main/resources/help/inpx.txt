INPX / online-колекції

MyHomeLib читає всі .inp усередині INPX, structure.info та archives.info. Запис книги зберігає ім'я архіву та archiveEntry. Повторний імпорт оновлює каталог без навмисного дублювання стабільних LibID.

Для online-колекції задайте URL у властивостях/майстрі. Шаблон URL може містити {archive}, {file}, {entry}. Якщо книга не локальна, команда читання спочатку завантажує потрібний файл/архів у колекцію. Скасування прибирає .part.
