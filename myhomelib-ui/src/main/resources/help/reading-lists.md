# Списки читання

**Списки читання** — це власні впорядковані списки книг. Вони не змінюють групи або смарт-колекції.

- Створюйте, перейменовуйте та видаляйте списки.
- **Додати вибрані книги** додає всі книги, позначені прапорцями в основній таблиці; якщо прапорців немає — додається поточна вибрана книга.
- У контекстному меню **«Додати до списку читання»** одна книга додається окремо; якщо вона входить до checkbox-selection, додається вся поточна вибірка.
- Змінюйте порядок кнопками ↑/↓, клавішами **Alt+↑ / Alt+↓** або перетягуванням рядків.
- **«Почати/продовжити список»** відкриває першу доступну книгу в порядку списку, яка ще не завершена.
- Видалення списку не видаляє книги чи їхні файли; видалена з каталогу книга автоматично забирається зі списків.

Списки читання входять до portable backup/restore разом із membership і ручним порядком.
