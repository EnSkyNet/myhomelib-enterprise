# Підключення .hlc2

Сучасна SQLite-колекція MyHomeLib підключається напряму. Для оригінальної Delphi `.hlc2` MyHomeLib відкриває джерело лише для читання, створює сучасну sidecar SQLite-БД та переносить каталог, авторів, жанри, серії, `LibID`, файлові посилання, бібліотечні й особисті оцінки, прогрес та відгуки, якщо ці поля є у вихідній базі.

Оригінальний `.hlc2` не переписується. Перед першою міграцією все одно збережіть його резервну копію.
