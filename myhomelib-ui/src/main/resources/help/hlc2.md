# Підключення .hlc2

Сучасна SQLite-колекція підключається напряму. Для оригінальної Delphi .hlc2 MyHomeLib відкриває джерело тільки для читання, створює сучасну sidecar-БД та переносить книги, авторів, жанри, серії, LibID, бібліотечні/особисті оцінки, прогрес і файлові посилання. Оригінальний .hlc2 не переписується.
