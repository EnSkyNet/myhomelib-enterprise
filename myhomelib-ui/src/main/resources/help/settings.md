# Налаштування

Доступні мова інтерфейсу, зовнішні програми читання за розширенням, конвертери, параметри надсилання на пристрій, імпорт, читалка та інші налаштування програми. Вбудовані мови інтерфейсу: українська, англійська та болгарська. Для гарантованого оновлення всіх уже відкритих вікон після зміни мови перезапустіть MyHomeLib.
