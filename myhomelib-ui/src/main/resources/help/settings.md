# Налаштування

Доступні мова інтерфейсу, підтвердження небезпечних дій, відновлення сесії, пошуковий індекс, зовнішні програми читання за розширенням, Calibre та зовнішні конвертери, параметри надсилання на пристрій, імпорт, читалка, мережеві параметри й інші налаштування програми. Вбудовані мови інтерфейсу: українська, англійська та болгарська. Для гарантованого оновлення всіх уже відкритих вікон після зміни мови перезапустіть MyHomeLib.

WebDAV, плагіни та провайдери ШІ налаштовуються окремо через **Синхронізація, плагіни та ШІ...**. Секрети не повинні зберігатися у відкритому вигляді; якщо захищене сховище недоступне, залежні від секретів інтеграції вимикаються.
