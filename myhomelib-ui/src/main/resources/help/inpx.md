# INPX та онлайн-колекції

MyHomeLib читає всі `.inp` усередині INPX, а також `structure.info` та `archives.info`. Запис книги зберігає ім’я архіву та запис усередині нього (`archiveEntry`). Повторний імпорт оновлює каталог без навмисного дублювання стабільних `LibID`.

Для онлайн-колекції задайте URL у властивостях або майстрі. Шаблон URL може містити `{archive}`, `{file}`, `{entry}`. Якщо книга не локальна, команда читання спочатку завантажує потрібний файл або архів у колекцію. Скасування прибирає незавершений файл `.part`.
