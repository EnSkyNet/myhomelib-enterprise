# Відомості про книгу

Панель показує повні метадані каталогу, авторів/серію/жанри як переходи, видавництво, ISBN, мови, перекладачів, попередній перегляд змісту, текстові показники, дані читання та зображення.

Для локальних FB2/EPUB метадані можуть доповнюватися з файла. Для MOBI/PDF/DjVu використовується безпечний запасний сценарій. Файлові дані не перезаписують оцінку, прогрес, відгук або зв’язки каталогу, якщо це заборонено правилами об’єднання.

## Схожі книги та дублікати сторінок
Book Details показує локально обчислені «Схожі книги». Для CBZ/CBR/CB7 доступна перевірка точних дублікатів сторінок; результат є лише звітом і нічого автоматично не видаляє.
