# Відомості про книгу

Панель показує повні catalog metadata, авторів/серію/жанри як посилання, видавництво, ISBN, мови, перекладачів, TOC preview, text metrics, reading data та зображення.

Для локальних FB2/EPUB metadata доповнюються з файла. Для MOBI/PDF/DjVu використовується безпечний fallback. Файлові дані не перезаписують rating/progress/review або catalog relations.
