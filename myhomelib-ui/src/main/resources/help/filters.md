# Єдині фільтри

Фільтри мови, року, формату, локальної наявності, стану читання, діапазону оцінок і книг без оцінки використовують один `BookFilterSpec` у навігації, SQL-запитах таблиці та Lucene.

Швидкий фільтр таблиці змінює той самий стан. `AND` вимагає виконання всіх умов; `OR` приймає книгу, що відповідає хоча б одній активній умові. Скидання повертає профіль до стандартного стану.
