Читалка

Вбудована читалка на JavaFX Canvas не використовує WebView для сторінок книги. Підтримуються FB2/FBD, FB2.ZIP/ZIP, EPUB, TXT, а також MOBI/PRC/AZW/AZW3 без DRM для непакованого формату або PalmDOC; HUFF/CDIC потребує конвертації. Доступні зміст, пошук, форматований текст, сноски, внутрішні посилання, закладки, виділення/копіювання, теми, поля, шрифти, вирівнювання, переноси, жести натискання/гортання, автопрокрутка та збереження позиції.

Для інших форматів налаштуйте зовнішню програму через **Налаштування → Зовнішнє читання**.

Текст виділяється звичайним перетягуванням лівою кнопкою миші. Після виділення одразу з’являється меню «Підсвітити / Нотатка / Словник / Переклад / Копіювати». На сенсорному екрані довге натискання виділяє слово; жести гортання залишаються доступними для перегортання сторінок.
