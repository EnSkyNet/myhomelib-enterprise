# Читалка

MyHomeLib має кілька вбудованих режимів читання. Текстова JavaFX Canvas-читалка не використовує WebView для сторінок книги та підтримує FB2/FBD, FB2.ZIP/ZIP, EPUB, TXT/Markdown, а також MOBI/PRC/AZW/AZW3 без DRM для непакованого формату або PalmDOC; HUFF/CDIC потребує конвертації. Для текстових форматів доступні зміст, пошук, форматований текст, сноски, внутрішні посилання, закладки, виділення/копіювання, теми, поля, шрифти, вирівнювання, переноси, жести натискання/гортання, автопрокрутка та збереження позиції.

PDF відкривається у вбудованому посторінковому переглядачі; зашифрований PDF може запросити пароль, який читалка не зберігає. CBZ/CBR відкриваються у вбудованому переглядачі коміксів із лінивим завантаженням сторінок. MP3/M4B відкриваються у вбудованому аудіорежимі зі збереженням позиції. Можливості пошуку, анотацій та навігації відрізняються залежно від типу документа.

Для інших форматів налаштуйте зовнішню програму через **Налаштування → Зовнішнє читання**.

У текстовій читалці текст виділяється звичайним перетягуванням лівою кнопкою миші. Після виділення одразу з’являється меню «Підсвітити / Нотатка / Словник / Переклад / Копіювати». На сенсорному екрані довге натискання виділяє слово; жести гортання залишаються доступними для перегортання сторінок.

## Профілі налаштувань Reader

Налаштування Reader можуть зберігатися глобально, для формату, для серії або тільки для поточної книги. Ефективний профіль визначається строго за пріоритетом книга → серія → формат → глобальний. У діалозі налаштувань показано джерело активного профілю та доступні дії «Застосувати глобально», «Зберегти для цього формату», «Зберегти для цієї серії», «Зберегти тільки для цієї книги» і «Очистити override». Очищення видаляє лише поточний активний override та відкриває наступний нижчий рівень; інші профілі не змінюються.
