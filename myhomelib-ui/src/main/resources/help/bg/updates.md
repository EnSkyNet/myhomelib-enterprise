# Онлайн обновявания

**Обновявания** показва `Автор → Нови книги / Обновени книги → книги`. Броячите се базират на catalog revision, получена от мрежово INPX обновяване.

Нова версия на изтеглена книга заменя локалния файл само след успешно изтегляне. Обновяването се отбелязва като обработено едва след успешен запис; мрежова грешка не скрива наличното обновяване.
