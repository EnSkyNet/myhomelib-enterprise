# Съществуващи .hlc2 колекции

Съвременна MyHomeLib SQLite колекция се свързва директно. При оригинална Delphi `.hlc2` база MyHomeLib отваря източника само за четене, създава модерна sidecar SQLite база и мигрира каталога, авторите, жанровете, сериите, `LibID`, файловите връзки, библиотечните/личните оценки, напредъка и рецензиите, когато тези полета съществуват в изходната база.

Оригиналният `.hlc2` не се презаписва. Запазете резервно копие преди първата миграция.
