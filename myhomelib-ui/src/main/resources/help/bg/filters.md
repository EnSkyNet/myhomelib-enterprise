# Единни филтри

Филтрите за език, година, формат, локална наличност, reading state, диапазон на оценките и книги без оценка използват един `BookFilterSpec` в навигацията, SQL заявките на таблицата и Lucene.

Quick filter на таблицата променя същото състояние. `AND` изисква всички активни условия; `OR` приема книга, която отговаря поне на едно. Reset връща профила към стандартното състояние.
