# Навигация в библиотеката

Левият панел съдържа Автори, Серии, Жанрове, Години, Езици, Архиви, Ключови думи, Групи, Отзиви, Обновявания, Прочетени, История и Всички книги.

При големи библиотеки авторите се зареждат със SQL по избраната начална буква, вместо всички наведнъж. Активният глобален филтър влияе и върху списъка с книги, и върху броячите на навигационните възли.

Изберете възел, за да отворите съответния набор книги. Назад и Напред възстановяват предишния или следващия навигационен контекст.
