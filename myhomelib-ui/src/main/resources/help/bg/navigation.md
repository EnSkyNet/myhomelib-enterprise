# Навигация в библиотеката

Страничният панел предлага Автори, Серии, Жанрове, Години, Езици, Архиви, Ключови думи, Групи, Отзиви, Обновявания, Прочетени, История и Всички книги.

При големи библиотеки авторите се заявяват по избраната начална буква в SQL, без зареждане на цялата таблица. Глобалният филтър влияе и върху броячите.
