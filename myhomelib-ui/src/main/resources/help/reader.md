# Reader

Вбудований Canvas Reader не використовує WebView для сторінок книги. Підтримуються FB2/FBD, FB2.ZIP/ZIP, EPUB, TXT, а також DRM-free MOBI/PRC/AZW/AZW3 (uncompressed або PalmDOC; HUFF/CDIC потребує конвертації); зміст, пошук, rich text, сноски, внутрішні посилання, закладки, виділення/копіювання, теми, поля, шрифти, justify, перенос, tap/swipe, автопрокрутка та збереження позиції.

Для інших форматів налаштуйте зовнішню програму у Налаштування → Зовнішнє читання.

Текст виділяється звичайним перетягуванням лівою кнопкою миші. Після виділення одразу з’являється меню «Підсвітити / Нотатка / Словник / Переклад / Копіювати». На сенсорному екрані довге натискання виділяє слово; swipe-жести залишаються доступними для перегортання.
