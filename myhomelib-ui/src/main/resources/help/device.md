# Надсилання на пристрій та конвертери

У налаштуваннях задайте папку пристрою, шаблон імені/підпапок, рекомендований Calibre `ebook-convert` та, за потреби, спеціальні зовнішні шаблони конвертерів. Якщо перетворення не потрібне, книга копіюється або витягується з архіву в оригінальному форматі.

Необов’язковий Calibre не постачається разом із MyHomeLib. Коли `ebook-convert` доступний, зареєстровані цільові формати включають EPUB, MOBI, AZW3, PDF, FB2, TXT, DOCX, HTMLZ, KEPUB, LIT, LRF, PDB, PMLZ, RB, RTF, SNB, TCR, TXTZ і ZIP. Доступність конкретної цілі визначається форматом джерела та активним провайдером конвертації; FB2.ZIP також підтримується як власне пакування MyHomeLib.

Після експорту можна виконати явно налаштовану команду після надсилання. Для зовнішніх шаблонів доступні змінні на кштал `%DEST%`, `%TMP%`, `%FILE%`, `%FILENAME%`, `%TITLE%`, `%AUTHOR%`, `%SERIES%` і `%BOOKID%`. Команди запускаються лише за явним налаштуванням користувача.
