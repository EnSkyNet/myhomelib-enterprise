# Відправка на пристрій та конвертери

У Налаштуваннях задайте папку пристрою, шаблон імені/підпапок і команди зовнішніх конвертерів. Підтримані сценарії fb2→EPUB/PDF/MOBI/LRF. Якщо конвертер не потрібний, файл копіюється/витягується в оригінальному форматі.

Після експорту можна виконати post-send command. У шаблонах/командах використовуються змінні призначення, тимчасового файла та імені файла. Команди запускаються тільки за явним налаштуванням користувача.
