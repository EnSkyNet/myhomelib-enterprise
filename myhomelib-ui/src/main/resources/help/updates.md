# Online Updates

Режим **Оновлення** показує `Автор → Нові книги / Оновлені книги → книги`. Лічильники базуються на catalog revision із online INPX.

Нова версія завантаженої книги замінює локальний файл тільки після успішного download. Update acknowledge виконується після успішного запису; помилка мережі не приховує оновлення.
