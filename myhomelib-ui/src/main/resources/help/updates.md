# Онлайн-оновлення

Режим **Оновлення** показує `Автор → Нові книги / Оновлені книги → книги`. Лічильники базуються на ревізії каталогу, отриманій із мережевого INPX-оновлення.

Нова версія завантаженої книги замінює локальний файл тільки після успішного завантаження. Оновлення позначається опрацьованим лише після успішного запису; помилка мережі не приховує запис про доступне оновлення.
