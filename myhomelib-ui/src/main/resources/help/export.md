# Експорт

Вибрані книги можна експортувати у вже наявному локальному форматі або, коли доступний сумісний конвертер, перетворити в інший формат через спільну матрицю можливостей `BookConverter`. Вбудовані конвертери та необов’язковий Calibre `ebook-convert` використовуються лише тоді, коли вони доступні для фактичного формату джерела. Для книги в архіві MyHomeLib витягує саме її `archiveEntry`, без ручного розпакування всього контейнера. Підтримуються шаблони імені файла та підпапки.

Список книг експортується в HTML, TXT або RTF, а поточну колекцію можна експортувати в INPX. Особисті дані — оцінки, прогрес, відгуки, групи, закладки, позиції Reader та історія — експортуються окремо від каталогу й прив’язуються до `LibID`, щоб переживати оновлення INPX.

Для Obsidian або Joplin у Менеджері анотацій доступний окремий Markdown-експорт: один файл на книгу, шаблони папки/імені/вмісту, необов’язковий YAML-заголовок і посилання назад у MyHomeLib. Повторний експорт за замовчуванням замінює лише файл MyHomeLib тієї самої книги; чужі нотатки не перезаписуються, а дублікати з числовими суфіксами автоматично не створюються.
