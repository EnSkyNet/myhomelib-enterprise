# Обслуговування колекції

Автоматичне оновлення стежить за заданим джерелом INPX/ZIP, використовує затримку стабілізації та відбиток стану, тому масові зміни книжкових файлів не створюють лавину однакових подій.

Очищення/ремонт завжди працює за схемою **Аналіз → Попередній перегляд без змін → Застосування → Звіт**. Перед ремонтом бази даних створюється резервна копія. Файли-сироти не видаляються автоматично.
