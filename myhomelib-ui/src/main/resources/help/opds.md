# OPDS

OPDS працює окремим модулем і за замовчуванням слухає тільки `127.0.0.1`. Доступні authors/series/genres/search/book/download та health endpoint.

Якщо bind address відкриває сервер у мережу, UI показує попередження. За потреби увімкніть Basic Auth. Списки пагіновані й не матеріалізують усю бібліотеку.
