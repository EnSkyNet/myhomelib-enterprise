# OPDS

OPDS працює окремим модулем і за замовчуванням слухає лише `127.0.0.1`. Доступні пагіновані канали авторів, серій, жанрів, пошуку та даних книги, локальне завантаження книг, OPDS 2.0 представлення колекцій/груп/обраного/продовження читання і перевірка стану `/health`; сумісність з OPDS 1.x збережена.

Loopback може працювати через HTTP. Будь-яке прив’язування поза loopback запускається лише через TLS/HTTPS; незахищений LAN-режим сервер блокує. У вікні **OPDS сервер** можна створити керований самопідписаний сертифікат або імпортувати X.509 PEM разом із незашифрованим приватним ключем PKCS#8 PEM. Інтерфейс показує суб’єкт, строк дії та SHA-256-відбиток. Після регенерації сертифіката відбиток змінюється, тому довіру на клієнтських пристроях потрібно налаштувати повторно.

Самопідписаний сертифікат не є автоматично довіреним: перед додаванням довіри на телефоні або читалці звірте SHA-256-відбиток із MyHomeLib. Керований PKCS12 зберігається в каталозі конфігурації; пароль — лише в зашифрованій оболонці `mhlenc:v1`. `myhomelib.opds.tls.keyStorePassword` і `MYHOMELIB_OPDS_TLS_KEYSTORE_PASSWORD` залишаються запасними способами для вручну налаштованого сховища ключів.

Можна ввімкнути Basic Auth або створити/відкликати scoped Bearer-токени з окремими правами читання каталогу та завантаження. Basic Auth має throttling невдалих спроб; сервер обмежує backlog і кількість одночасних запитів. `/health` за замовчуванням відкритий на loopback, але при LAN-доступі потребує Basic Auth або повертає HTTP 403, якщо Basic Auth вимкнено.

## Веб-бібліотека як PWA та офлайн-читання

Веб-бібліотека `/web/` має installable PWA shell. На loopback браузер може використовувати HTTP як secure-context виняток; доступ із LAN не послаблює чинну політику — сервер запускається лише через HTTPS/TLS.

Статичний app shell, manifest, іконки та offline fallback не містять даних бібліотеки або облікових даних. HTML/API з даними користувача не кешуються автоматично. Книга потрапляє в browser Cache Storage лише після явної дії **«Зберегти для читання офлайн»**; **«Видалити офлайн-копію»** очищає її кеш, а **«Очистити всі офлайн-копії»** видаляє всі явно збережені книги, не чіпаючи app shell. Одночасно зберігається не більше 20 completed offline-book caches; понад ліміт видаляється найстаріший. Сервер формує санітизований версійований Web Reader manifest, а не передає браузеру окремий EPUB/FB2 parser.

Прогрес під час офлайн-читання зберігається у локальній IndexedDB-черзі браузера з монотонним номером і часовою міткою та повторюється після відновлення мережі. Сервер не приймає старіший прогрес поверх новішого канонічного стану; точний повтор тієї самої позиції є ідемпотентним.
