# OPDS

OPDS працює окремим модулем і за замовчуванням слухає тільки `127.0.0.1`. Доступні канали авторів, серій, жанрів, пошуку, відомостей про книгу, завантаження та перевірки стану (`/health`).

Локальний режим зворотного зв’язку може працювати через HTTP. Будь-яке прив’язування до адреси поза локальним інтерфейсом дозволено запускати тільки через TLS/HTTPS; незахищений режим локальної мережі блокується сервером.

У вікні **OPDS сервер** можна ввімкнути HTTPS, створити керований самопідписаний сертифікат або імпортувати сертифікат X.509 у PEM разом із незашифрованим приватним ключем PKCS#8 у PEM. Для сертифіката показуються суб’єкт, строк дії та відбиток SHA-256. Після повторного створення сертифіката відбиток змінюється, тому довіру на клієнтських пристроях потрібно налаштувати повторно.

Самопідписаний сертифікат не є автоматично довіреним. Перед додаванням довіри на телефоні або читалці звірте відбиток SHA-256 з тим, що показує MyHomeLib. Керований PKCS12 зберігається в каталозі конфігурації; його пароль записується в налаштуваннях програми лише в зашифрованій оболонці `mhlenc:v1`. Системна властивість `myhomelib.opds.tls.keyStorePassword` та `MYHOMELIB_OPDS_TLS_KEYSTORE_PASSWORD` залишаються запасними способами для вручну налаштованого сховища ключів.

Базова автентифікація має обмеження частоти невдалих спроб. Сервер також обмежує чергу очікування та кількість одночасно оброблюваних запитів. За замовчуванням `/health` відкритий лише локально; при публікації в локальну мережу він потребує базової автентифікації, а якщо її вимкнено — повертає HTTP 403.
