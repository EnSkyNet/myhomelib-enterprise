# Пошук

Поля: автор, назва, серія, жанр, ключові слова, анотація, ім’я файлу, дата додавання, мова, рейтинг, рік, видавець.

Синтаксис: `%слово%` — пошук за шаблоном; `="точна фраза"` — точна фраза; `OR` — альтернатива; `title:`, `author:`, `series:`, `genre:`, `file:`, `lang:` — явне поле. Набори умов можна зберігати як профілі пошуку.
