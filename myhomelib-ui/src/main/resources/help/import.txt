# Імпорт

Можна імпортувати окремий файл, каталог, INPX або архів. Реєстр форматів підтримує FB2/FBD, EPUB, TXT/TEXT/Markdown, PDF, MP3, M4B, MOBI/PRC, AZW/AZW3, DjVu, DOC/DOCX, ODT, RTF, HTML/XHTML, CHM, CBZ/CBR та інші зареєстровані типи з різними можливостями метаданих, обкладинок, повнотекстового індексування й читання. Для MOBI/PRC/AZW/AZW3 без DRM вбудоване читання працює для непакованого формату або PalmDOC; HUFF/CDIC потребує конвертації.

Архіви: ZIP/FB2ZIP/CBZ/JAR, 7z, RAR/CBR, TAR, TAR.GZ/TGZ, TAR.BZ2/TBZ2, TAR.XZ/TXZ і CPIO. Конкретна книга може зберігатися як запис усередині контейнера. Великі записи обробляються потоково або через тимчасові файли з обмеженнями розміру.

Імпорт каталогів і великих INPX виконується обмеженими пакетами, щоб не накопичувати всю бібліотеку в оперативній пам’яті. Пошуковий індекс перебудовується один раз після масової операції.
