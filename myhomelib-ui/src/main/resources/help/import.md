# Імпорт

Можна імпортувати окремий файл, каталог, INPX або архів. Метадані читаються з FB2/FBD, EPUB, TXT і MOBI/AZW/AZW3. MOBI/PRC/AZW/AZW3 без DRM також відкриваються у вбудованій читалці для непакованого формату або PalmDOC; HUFF/CDIC потребує конвертації. PDF, DJVU, DOC/DOCX/ODT, RTF, HTML/XHTML, Markdown, CHM та інші підтримувані документи каталогізуються відповідно до можливостей їхніх адаптерів.

Архіви: ZIP/FB2ZIP/CBZ/JAR, 7z, RAR/CBR, TAR, TAR.GZ/TGZ, TAR.BZ2/TBZ2, TAR.XZ/TXZ і CPIO. Великі записи обробляються потоково або через тимчасові файли з обмеженнями розміру.

Імпорт каталогів і великих INPX виконується обмеженими пакетами, щоб не накопичувати всю бібліотеку в оперативній пам’яті. Пошуковий індекс перебудовується один раз після масової операції.
