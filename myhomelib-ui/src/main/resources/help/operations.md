# Центр операцій

**Центр операцій** показує довготривалі та завершені операції поточного сеансу: тип, етап, прогрес, час початку/завершення, тривалість, результат і деталі помилки.

Для активної операції, яка підтримує скасування, доступна команда **Скасувати**. Скасування вважається завершеним лише після фактичного завершення cleanup активної роботи. Завершені записи можна очистити окремою командою; це не видаляє книги або результати успішних операцій.

Якщо інша дія тимчасово несумісна з активною операцією, MyHomeLib має показати причину блокування замість запуску конфліктної операції.
