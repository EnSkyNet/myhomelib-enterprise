# Анотації та нотатки

Робочий простір **Анотації та нотатки** показує підсвітки й нотатки з усієї бібліотеки. Доступні пошук за книгою, цитатою, текстом нотатки, розділом і тегами, а також фільтри за книгою, типом, кольором, тегом і датою.

Можна відкрити анотацію в Читалці, редагувати нотатку, колір і теги, видалити вибрані записи з підтвердженням та скасувати останнє видалення. Пакетні дії дозволяють змінити колір або додати/зняти теги для вибраних анотацій.

Експорт підтримує UTF-8 CSV, Markdown, JSON, самодостатній HTML, конспект і knowledge-management Markdown для Obsidian/Joplin. Для Markdown/HTML та knowledge-export доступні шаблони; публікація виконується через завершений тимчасовий файл, щоб помилка або скасування не залишили частковий результат.

## Експорт у Readwise
Кнопка Readwise експортує анотації для книг із поточного виділення; якщо виділення немає — для активного book-filter, а без нього — для всієї бібліотеки. Незмінені анотації повторно не надсилаються.
