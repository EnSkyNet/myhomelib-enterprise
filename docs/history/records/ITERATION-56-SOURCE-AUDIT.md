# Ітерація 56 — міжмодульна перевірка та виправлення

Дата: 9 жовтня 2026 року. База: ітерація 55. Версія: 8.0.0.

## Виправлення

1. `myhomelib-reader`: ZipParser раніше відкривав BookSource і повторно копіював ZIP
   перед КОЖНОЮ спробою декодування імен записів. Тепер ZIP тимчасово зберігається
   рівно один раз, а всі дозволені кодування перевіряються на одному staging-файлі.
   Прибирання тимчасового файлу відбувається у `finally`. Прибрано дубль CP866/IBM866.
   Новий регресійний тест перевіряє однократне читання джерела й кириличні імена CP866.
2. `myhomelib-ui`: PositionAutosaveCoordinator серіалізував збереження, але не
   порівнював ревізії двох уже захоплених snapshot, тож старіший міг зберегтись
   після новішого. Тепер для кожної книги зберігається номер останньої успішної
   ревізії, старіший запис пропускається, невдалі збереження залишаються в черзі.
   Додано регресійний тест, що відтворює зміну порядку завершення.
3. Семантика `flush()`: результат повідомляє успіх поточної книги (як вимагали
   чинні тести та клієнтський код); старі помилки повторюються окремо і
   враховуються в `closeAndFlush()`.

## Перевірки

- Maven offline з Java 21 та Linux/Xvfb: повний реактор 21 модуль; результати
  повного тестового прогону — в зовнішньому звіті цієї ітерації.
- Адресний `ZipParserTest`: 3 тести, без помилок.
- Адресні `AutosaverConcurrencyTest` + `PositionAutosaveCoordinatorTest`:
  12 тестів, без помилок.
- Додатково поза репозиторієм перевірені 3 надані FB2-архіви через
  RealFb2ReaderProbeTest: навігація, довжина тексту, метадані, розділи.

## Обмеження

Огляд і автоматичні перевірки не гарантують відсутності кожного можливого дефекту.
Windows-специфічні інтеграції, повний графічний сценарій у Windows, зовнішні
хмарні сервіси, а також частина ручних або opt-in тестів тут не перевірені.
