# MyHomeLib R18 / 8.0.0 — checkpoint аудиту бюджетів архівів

**Дата:** 2026-10-10
**База:** `MyHomeLib-R18-8.0.0-Iteration83-archive-transaction-audit-source.zip`
**Статус:** локальний офлайн-regression PASS; Windows/live acceptance не виконано.

## Знайдені та виправлені дефекти

1. **TAR/CPIO — не враховувалися пропущені елементи.** Тепер кожний елемент явно читається до кінця в межах лімітів; неявне декодування під час переходу до наступного запису більше не обходить облік. `countBooks()` використовує той самий обмежений потік і повертає `-1`, якщо підрахунок не можна завершити без перевищення бюджету.
2. **7z — пропущені елементи могли декодуватися всередині `getNextEntry()`.** Додано контрольоване читання пропущених елементів. `countBooks()` переходить на метадані `getEntries()`, не запускаючи декодер заради простого підрахунку.
3. **RAR — solid-архіви.** Junrar може розпаковувати попередні елементи у внутрішній `NullOutputStream`, коли відкривається пізніший solid-елемент. Для архівів, де потрібна послідовна обробка, пропущені елементи тепер явно споживаються через bounded reader. Помилка такого споживання завершує імпорт, а не дозволяє повторний неявний пропуск.
4. **ZIP — загальний ліміт перевірявся після запису тимчасового файлу.** Копіювання тепер зупиняється під час запису, якщо перевищено бюджет поточного елемента або загальний бюджет архіву. Перевищення загального бюджету є фатальним для операції; перевищення ліміту окремого елемента лишається контрольованим пропуском цього елемента.
5. **Спільний механізм** `ArchiveEntryImportSupport` отримав `discardEntry()` та `copyEntryBounded()` із перевіркою фактично прочитаних байтів, обмеженням переривання та overflow-safe арифметикою.
6. **Пакування вихідного коду:** static release gate виявив відсутні executable bits у 10 кореневих shell-скриптів. Права виправлено; скрипти тепер зберігаються як executable у вихідному ZIP.

Production-файли: `ArchiveEntryImportSupport.java`, `StreamArchiveImporter.java`, `SevenZImporter.java`, `RarImporter.java`, `ZipImporter.java`.
