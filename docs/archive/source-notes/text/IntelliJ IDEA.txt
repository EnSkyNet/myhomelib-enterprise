Це означає, що проблема полягала саме в самій сесії PowerShell 
всередині терміналу IntelliJ IDEA, яка за замовчуванням використовувала 
стару системну кодову сторінку Windows (CP1251 або IBM866).
 Команда chcp 65001 примусово перевела консоль у режим UTF-8.
 Щоб вам не доводилося вводити ці команди вручну щоразу при відкритті
 терміналу, можна зробити так, щоб IntelliJ IDEA автоматично запускала PowerShell 
 із правильним кодуванням.Як автоматизувати це назавжди:Відкрийте Settings (Ctrl + Alt + S)
 в IDEA.Перейдіть у розділ Tools ➔ Terminal.Знайдіть поле Shell path. 
 За замовчуванням там вказано просто powershell.exe.Змініть цей шлях, 
 додавши аргументи для автоматичного перемикання кодування при старті
 powershell.exe -NoExit -Command "[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; chcp 65001"
