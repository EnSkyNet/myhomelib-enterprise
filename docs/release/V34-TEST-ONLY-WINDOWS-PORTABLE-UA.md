# V34 Windows Portable: лише тестовий кандидат

Це **не фінальний реліз**, не інсталятор і не підписаний продукт. Збірка призначена для обмеженого приймального тестування на Windows 11 x64, зокрема на комп'ютері з 4 ГБ RAM.

## Як отримати саме перевірений ZIP

1. Відкрийте GitHub Actions → **V34 Windows test-only portable**, виберіть успішний запуск на гілці `master`. Після злиття початкового workflow він запускається автоматично; надалі його можна запустити вручну через `workflow_dispatch`.
2. У розділі Artifacts завантажте `v34-test-only-windows-portable-<40-значний-SHA>`. У ньому ZIP Portable, `SHA256SUMS`, двічі перевірений `release-candidate-integrity-windows.json` і звіт Unicode Portable smoke.
3. На Windows перевірте SHA-256 ZIP командою `Get-FileHash -Algorithm SHA256 .\<ім'я-архіву>.zip` та звірте з `SHA256SUMS`. Перевірте, що `candidateSha` в JSON збігається з SHA в назві артефакту та запуску GitHub Actions.
4. Розпакуйте ZIP у **новий тестовий каталог**. `MyHomeLib.exe` містить власний Java 21 runtime. Не запускайте цей кандидат поверх робочого встановлення чи бази.

## Послідовність першого живого тесту

1. Увійдіть під звичайним користувачем Windows. Використайте новий каталог із маркером `myhomelib2.ini` та нові тестові дані; не підключайте `Flib.db`, робочу колекцію або папки синхронізації.
2. Запустіть Portable, перевірте початкове вікно, перемикання мови, читання синтетичної FB2/EPUB/PDF, закриття і повторний запуск. Якщо програма не стартує, збережіть лог та скриншот помилки.
3. На 1, потім 100 синтетичних книгах: імпорт, пошук, Organizer **попередній перегляд → застосування**, скасування, Undo та безпечне відновлення після примусового завершення. Перевірте SQLite `PRAGMA quick_check` **лише на тестовій базі**.
4. Конвертуйте тестову FB2 в EPUB, перевірте EPUB, роботу скасування та очищення тимчасових файлів. Переконайтеся, що інші вікна залишаються чутливими під час конвертації.
5. На цільовому Windows 11 із 4 ГБ RAM виконайте 1–2 години сценаріїв запуск → імпорт → пошук → читання → конвертація → повторний запуск. Зберіть working set, private bytes, heap/GC, handles, CPU, час відкриття та статус тимчасових файлів. Скрипт `tools/windows-target-memory-soak.ps1` потребує підтвердженого host/session binding і функціонального acceptance для того ж SHA; не обходьте його вимоги.

**Що доводить автоматичний CI:** повний Windows Maven `-Pproduction clean verify`, статичні політики, запуск нативного `jpackage` launcher через `--release-smoke`, наявність конвертерів, запуск Portable після розпакування в шлях із Unicode, включений Java runtime та SHA-256 цілісність.

**Чого він не доводить:** роботу інтерактивного GUI на вашому комп'ютері, фізичні пристрої, реальні мережеві провайдери, підпис, Defender/SmartScreen і поведінку при дефіциті RAM. Не використовуйте тестовий ZIP для робочої бібліотеки до завершення цих перевірок.
