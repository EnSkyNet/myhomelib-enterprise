# Перевірка назв уже створених папок авторів (лише читання)

**Призначення.** Побудувати CSV зіставлення папок авторів із **окремими полями** `authors.first_name`, `authors.middle_name`, `authors.last_name` SQLite-каталогу. На відміну від евристики за словником поширених імен, ця перевірка спирається на структуровані поля. Але ці поля теж можуть містити помилки первинного імпорту, тому CSV — **план для ручної перевірки**, а не безумовна команда перейменування.

**Підготовка (Windows):** завершити MyHomeLib штатно, зробити коректну резервну копію `Flib.db` та пов’язаного стану SQLite (WAL/SHM, якщо є). Надалі працювати саме з **копією** каталогу й **копією** папок, а не з робочою бібліотекою.

З кореня вихідного проєкту:

```powershell
python tools\audit-author-folders.py "D:\Другие" --catalog "D:\Flib\Flib.db" --output "$env:USERPROFILE\Desktop\author-folder-review.csv"
```

У CSV (`UTF-8 BOM`, роздільник `;`) наявні поточна папка, пропозиція, статус і підстава. Статуси:

- `ПІДТВЕРДЖЕНО_КАТАЛОГОМ` — одна відповідність у структурованих полях SQLite; цільової папки немає, але рішення все одно потрібно переглянути.
- `ПІБ_ВЖЕ_ПРАВИЛЬНИЙ` — поточна назва відповідає формату «Прізвище Ім’я [По батькові]» із каталогу.
- `ЦІЛЬОВА_ПАПКА_ІСНУЄ` — потенційна колізія або необхідність об’єднання; **не перейменовувати масово**.
- `КОНФЛІКТ_АВТОРІВ` — кілька різних структурованих ПІБ відповідають одній назві папки.
- `НЕПІДТВЕРДЖЕНЕ_ПРИПУЩЕННЯ`, `ЙМОВІРНО_ПРАВИЛЬНО`, `ПОТРЕБУЄ_ПЕРЕВІРКИ`, `ОДНЕ_ІМЯ_АБО_ПСЕВДОНІМ` — у каталозі немає однозначного відповідника; словник не є підтвердженням.

**Гарантії та обмеження:** скрипт не перейменовує, не видаляє, не переносить книги й не записує в базу даних. Зчитує тільки перший рівень каталогів; вкладені шляхи та багатокнижкові архіви потребують окремого планувальника. Excel-подібні формули в назвах екрануються лише у звіті. Якщо цільова папка існує, варто перевірити її книги й шлях кожного артефакту в SQLite перед будь-яким об’єднанням. Ніколи не застосовувати масові перейменування файловим менеджером без синхронного оновлення каталогу.

Діагностичний запуск без `--catalog` залишено для випадків, коли SQLite не надано: усі пропозиції за словником мають **непідтверджений** статус.

Перевірка самого скрипту:

```bash
python -m unittest discover -s tools/tests -p test_audit_author_folders.py -v
```
