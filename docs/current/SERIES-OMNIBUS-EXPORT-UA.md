# Консолідація серій під час експорту на пристрій (V34)

## Результат

Режим **«Зібрати всю серію автора в одну книгу»** створює **один читабельний
електронний том**, а не архів із незалежними файлами. Один вибраний том
достатній для пошуку всіх книг тієї самої серії й автора.

Програма визначає автора за ID, зіставляє назву серії та сортує за
явними номерами томів у назвах (якщо вони присутні) або індексом серії.
Коли один файл охоплює томи 1–2, показує окремо кількість вихідних
файлів і кількість томів.

## Формати одного тому

| Формат | Що створюється | Навігація | Збереження матеріалів |
|---|---|---|---|
| FB2 (основний) | Один документ FictionBook | Розділ для кожного тому, вкладені глави й початковий загальний зміст із переходами | Оригінальні секції, базове форматування, зображення, примітки й внутрішні посилання |
| FB2.ZIP | Один ZIP, рівно один об'єднаний FB2 | Як у FB2 | Як у FB2 |
| EPUB | Один EPUB 3 | Загальний зміст на початку, томи й глави у вкладеному EPUB TOC з посиланнями на XHTML-якорі | Поки текстовий режим без первинних ілюстрацій та стилів |
| TXT | Один текстовий файл | Заголовок кожного тому | Суцільний текст без гіперпосилань |

Загальний зміст FB2 є окремою секцією з активними внутрішніми
посиланнями на кожен том і главу. Вкладені section/title також формують
дерево змісту читалки. Ідентифікатори з різних джерел перейменовуються,
а посилання на зображення та примітки коректно переписуються.

## Архівування — окрема опція

Для звичайного копіювання вибирають 7z (за замовчуванням), ZIP або
без архіву, а також стиснення: максимальне (за замовчуванням),
звичайне чи швидке. Для консолідованого тому архівування початково
вимкнене, щоб файл одразу відкривався у читалці.

RAR уже підтримується для читання й імпорту. Створення нового RAR
поки не підключене: для цього потрібен сумісний зовнішній архіватор;
Junrar не виконує стискання RAR.

## Обмеження й перевірка

- Вихідні файли залишаються незмінними; результат створюється в
  приватній тимчасовій папці й публікується лише після успішної перевірки.
- Пошкоджений XML, небезпечні DTD/зовнішні сутності, перевищення
  бюджетів ресурсу, відсутня книга чи скасування не повинні залишати
  частково готову «повну серію».
- Для комп'ютерів з 4 ГБ RAM FB2 обробляється по одному документу,
  а не ціла бібліотека в пам'яті. Застосовано обмеження за розміром
  вхідного XML, глибиною, сумарним обсягом, кількістю глав і книг.
- Не слід помилково позначати PDF, MOBI чи DRM-захищені джерела як
  безвтратно об'єднані FB2: потрібен спеціалізований конвертер.
- Синтетичні тести перевіряють дерево глав, нотатки, дубльовані ID,
  кількість томів, ZIP-обгортку, заборону DTD і прибирання неповних файлів.
  Авторські книжкові файли користувача до репозиторію не додаються.

Усі зміни в окремій гілці з повідомленнями [skip ci], щоб не витрачати
додаткові платні хвилини GitHub Actions. Maven, CodeQL і повний
Windows Portable для цієї гілки ще не запускалися.
Не об'єднувати зміни з перевіреним master до успішного повного CI.
