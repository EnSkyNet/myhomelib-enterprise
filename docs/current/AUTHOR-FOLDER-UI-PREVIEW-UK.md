# Перевірка порядку імен у папках авторів у MyHomeLib

Починаючи з етапу 5, майстер **Упорядкування бібліотеки** має кнопку **«Перевірити порядок імені автора»** на першій сторінці. Вона доступна для **поточної колекції** з локальною SQLite-базою та визначеним коренем бібліотеки.

## Як користуватися

1. Відкрийте поточну колекцію та майстер упорядкування.
2. Виберіть «Поточна колекція», натисніть «Перевірити порядок імені автора».
3. Введіть **лише назву однієї папки**, наприклад `Алёна Васильева`, без `D:\` та вкладених шляхів.
4. Дочекайтеся відповіді. Програма перевіряє структуровані поля `first_name`, `middle_name`, `last_name` для всіх локальних книг у папці (включно із вкладеними записами), порівнює очікувану назву та попереджає про існуючу цільову папку.
5. Якщо всі книги підтверджують одного автора, буде показано пропозицію на зразок `Васильева Алёна`. Інакше показується причина, чому автоматично визначити порядок не можна.

Перевірка використовує **тільки читання**, працює у фоновому потоці і **не змінює файли, SQLite або журнали операцій**. Це не повна перевірка SHA-256, архівів чи `book_artifacts`, тому її результат **не є дозволом на перейменування**.

Для реального ремонту однієї папки поки залишається окремий інструмент `tools/repair-author-folder.py`, описаний в `docs/current/AUTHOR-FOLDER-REPAIR-UK.md`. Для нього потрібно повністю закрити MyHomeLib та попередньо виконати перевірку на копії бібліотеки.

## Відомі обмеження

- Перевірка вікна не підтримує довільні зовнішні папки, віддалені колекції або інші формати бази даних.
- Немає масового перейменування папок чи змін фізичних шляхів. Це навмисно, щоб не пошкодити вже перенесені книги.
- Порядок ПІБ визначається **лише структурованими полями**. Імена без підтвердженого прізвища не переставляються на основі здогадів.
- За відсутності збігу `collection_root` з поточним коренем колекції папка не вважається зареєстрованою в цьому корені.
- Приймальне тестування на реальній Windows-бібліотеці необхідне перед подальшою інтеграцією змін файлової системи в GUI.
