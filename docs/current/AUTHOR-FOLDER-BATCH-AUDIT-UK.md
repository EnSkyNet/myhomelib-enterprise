# Пакетна перевірка папок авторів — MyHomeLib R18

## Як отримати звіт

1. Відкрийте **Упорядкування бібліотеки** й оберіть **Поточна колекція**.
2. Натисніть **Перевірити всі папки авторів (CSV)**.
3. Збережіть звіт **поза коренем бібліотеки**. MyHomeLib опрацює структуровані поля авторів у поточній SQLite-колекції та назви папок у файловій системі.
4. Відкрийте файл у табличному редакторі. Стовпці й текстові стани відповідають поточній мові застосунку.

Режим **лише читає** бібліотеку та SQLite. Записується тільки окремо обраний CSV-звіт. База даних, файли книг та їхні папки не змінюються. CSV не є готовим планом виконання перейменувань.

## Як читати стани

- **Можлива назва з прізвищем на початку** — усі пов'язані книги мають узгоджені структуровані дані, а папка з новою назвою не знайдена. Для реального перейменування все одно потрібні незалежні перевірки фізичних файлів і посилань у БД.
- **Поточна назва вже відповідає даним** — змінювати нічого не треба.
- **Неможливо підтвердити** — бракує структурованого автора або книги містять різні дані; автоматичне перейменування небезпечне.
- **Цільова папка вже існує** — потрібна ручна перевірка колізії, зокрема для відмінностей лише у регістрі на Windows.
- **Немає зареєстрованих локальних книг** — папка існує на диску, але не має відповідних активних локальних записів у поточній колекції. Це не означає, що її вміст можна видаляти.

## Межі перевірки

- Перевіряються безпосередні папки кореня обраної колекції та записи книг у цих папках і їхніх підпапках.
- Дані беруться з полів `first_name`, `middle_name`, `last_name`. Псевдоніми, різні автори в одній папці та неповні відомості не вгадуються за словником.
- Повна перевірка SHA-256, спільних архівів і узгоджене оновлення `books` / `book_artifacts` **не виконуються**. Пропозиція не є дозволом на файлову операцію.
- Через зміну колекції чи ручні зміни на диску відомості у звіті можуть застаріти. Перед будь-якою операцією відновлення потрібні свіжа перевірка та резервна копія.
- Обсяг звіту обмежений 100 000 папок за один запуск. Для більших дерев потрібне розбиття на колекції.
